# Example prompts for the Microsoft Advertising MCP server

These work as written in Claude, ChatGPT, Cursor, Codex, Gemini CLI and the other clients listed in the README. Anything that changes the account comes back as an approval first.

## Read and report

- With Sprites, how did Microsoft Ads do last 30 days vs the 30 before?
- Use Sprites to compare CPA on Microsoft Ads and Google Ads for the same campaigns.
- Ask Sprites which Microsoft Ads keywords spent over $50 with no conversion last month.
- Ask Sprites to check our Microsoft Ads conversion goals and say if any are not recording.

## Change, create and launch

- Have Sprites add those keywords to a negative keyword list.
- With Sprites, build a Microsoft Ads search campaign for our pricing page at $30/day.
- Use Sprites to pause the Bing campaigns with zero conversions in 60 days.
- With Sprites, raise the Brand campaign budget on Microsoft Ads to $25/day.
- Have Sprites write new headlines for our Microsoft Ads search ads.

## Recurring

- Use Sprites to send me a weekly Microsoft Ads summary next to Google Ads.

## Tips

- Name the campaign, ad set or page in full. Sprites receives only the request, not the earlier chat.
- Say the period ("last 30 days", "this quarter"); your client passes today's date so it resolves correctly.
- Working on several businesses? Say "switch to <business name>" first (`choose_business`).
- To compare channels, ask about them in one request, for example "compare Google and Meta CPA last month".
